# Business Mobi Asbestos

Business Mobi in Asbestos: a five-page business website template for phones (home, about, services, contact and a typography reference).

**[Live demo](https://mobifreaks.github.io/Asbestos-Business-Mobi/)** ·
[Download zip](https://github.com/mobifreaks/Asbestos-Business-Mobi/archive/HEAD.zip) ·
[All 22 templates](https://munawarahmed.com/mobifreaks)

![Business Mobi Asbestos on a phone](screenshot.webp)

## Use it

No build step. Download the zip, open `index.html`, and replace the placeholder text and images with your own.

## Tech

HTML, CSS and jQuery 1.12.
